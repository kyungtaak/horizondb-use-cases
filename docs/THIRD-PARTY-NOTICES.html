문서 출처와 라이선스

Fleet Intelligence의 한국어 발표자료와 기술 설명은 아래 프로젝트의 시나리오와 발표자료 디자인을 참고했습니다. API, 데이터 구조, 모델 호출과 시연 설명은 현재 HorizonShip 구현에 맞춰 수정했습니다.

  • 원본 저장소: https://github.com/FranckPachot/horizondb-fleet-intelligence
  • 참고한 커밋: 783b59a8ea51d629cfd0448d41b8bc8d6384bbfb
  • 최초 가져온 날짜: 2026-09-15
  • 원본 문서와 이미지: 해당 커밋의 demo 폴더
  • 원본 라이선스: 해당 커밋의 LICENSE

처음에는 원본 HTML·Markdown 문서 5개와 이미지 7개를 보관했습니다. 현재는 중복 보관본을 제거하고, 발표자료에 사용하는 원본 CSS만 slides-base.css에 분리했습니다. 스타일 규칙은 유지하며 줄바꿈과 파일 끝 공백은 정규화합니다. 한국어 문서의 구성과 추가 스타일은 이 저장소에서 관리합니다. 원문은 위 커밋 링크에서 확인할 수 있습니다.

현재 앱에서 촬영한 시연 이미지는 유지하며, 이미지에 포함된 OpenStreetMap 저작자 표시도 보존합니다. PowerPoint와 원본 동영상은 가져오지 않았습니다. 기존 시연용 영상 폴더는 이번 정리에서 변경하지 않았습니다.

문서나 추출한 CSS를 재배포할 때는 아래 저작권 고지와 MIT 라이선스도 함께 전달합니다.
