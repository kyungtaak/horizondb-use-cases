기술 설명 발표자료

HorizonDB가 맡는 일과 외부 모델이 맡는 일을 구분합니다.

데이터 저장·SQL 처리·확장 함수와 pipeline은 DB에서 연결합니다. 실제 모델 추론은 연결된 외부 endpoint에서 실행됩니다. PostgreSQL 확장 생태계의 기능과 HorizonDB의 AI 연계 기능을 함께 활용하는 데모입니다.
